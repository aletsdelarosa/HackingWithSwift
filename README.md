# Hacking With Swift

This repo contains my implementation of the projects of Hacking With Swift.

These projects are built with SwiftUI for macOS and can be opened and run with Xcode.

## Projects

- **[Project 1: WeSplit](./Project1)** — A check calculator that splits a bill between people and applies a tip percentage.
- **[Project 2: Guess The Flag](./Project2)** — A small game about guessing flags.
- **Project 3: Modifiers** — A lesson about modifiers (No code written).
- **[Project 4: BetterRest](./Project4)** — An app that allows you to calculate when do you need to go to sleep. It uses ML to calculate it based on hours you want to sleep, coffee you drink and wake up time.
- **[Project 5: Word Scramble](./Project5)** — A words game.

## Requirements

- macOS
- Xcode

## Running a project

1. Open the project’s `.xcodeproj` file in Xcode.
2. Select the macOS run destination.
3. Build and run the project with **Product > Run**.
