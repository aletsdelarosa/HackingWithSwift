# Hacking With Swift

This repo contains my implementation of the projects of Hacking With Swift.

These projects are built with SwiftUI for macOS and can be opened and run with Xcode.

## Projects

- **[Project 1: WeSplit](./Project1/Project1.xcodeproj)** — A check calculator that splits a bill between people and applies a tip percentage.

## Requirements

- macOS
- Xcode

## Running a project

1. Open the project’s `.xcodeproj` file in Xcode.
2. Select the macOS run destination.
3. Build and run the project with **Product > Run**.
